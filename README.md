# پلتفرم جامع مدیریت کسب‌وکارهای خدماتی

پیاده‌سازی فول‌استک پلتفرم SaaS چندمستأجری بر اساس سند نیازمندی‌ها
(`docs/PRD_fa.md`) — هسته مشترک (CORE) + ماژول‌های هسته کسب‌وکار
(CRM, SCH, FIN, ATT, MSG, SUB, CAMP, INV, HR, MKT, SHOP, DOC, RPT, APP).

## استک فنی

| لایه | فناوری | نسخه |
|---|---|---|
| بک‌اند | NestJS + Fastify/Express | ۱۲.x (ESM) |
| دیتابیس | PostgreSQL + Prisma ORM | ۱۸ / ۷.x |
| کش / صف | Redis + BullMQ-ready | ۸ / ۶.x |
| فرانت | Next.js App Router + React ۱۹ + Tailwind v4 | ۱۶ / ۱۹ |
| زبان | TypeScript | ۷.x |
| اجرا | Docker + Docker Compose + Turborepo + pnpm | — |

## معماری

```
apps/
  api/        NestJS REST API (نسخه‌بندی /api/v1)
  web/        رابط کاربری فارسی و RTL (Next.js)
packages/
  db/         Prisma schema + migrations + seed
  shared/     تایپ‌ها، رجیستری ماژول‌ها، مجوزها، صنف‌ها
  config/     پیکربندی مشترک
```

الگوی معماری: **Modular Monolith چندمستأجری**. هر ماژول PRD یک NestJS module
مستقل با مرز مشخص است و همه‌ی داده‌ها با `tenantId` (و در موارد لازم
`branchId`) ایزوله می‌شوند.

## راه‌اندازی سریع (توسعه)

```bash
cp .env.example .env
pnpm install
docker compose -f docker-compose.dev.yml up -d   # postgres + redis (+adminer :8080)
pnpm db:migrate
pnpm db:seed
pnpm dev                                         # api :4000  |  web :3000
```

- API: http://localhost:4000/api/v1
- Swagger: http://localhost:4000/api/docs
- Web: http://localhost:3000
- ورود آزمایشی: موبایل `09121111111` و کد `123456` (فقط در حالت توسعه)
- فهرست کامل اکانت‌های توسعه (مالک، عضو تیم، شاگرد، اپراتور پلتفرم):
  `docs/DEV_ACCOUNTS.md`

## اجرای کامل با Docker

```bash
docker compose up -d --build
```

سرویس‌ها: `postgres`, `redis`, `api` (:4000), `web` (:3000).

## ماژول‌های پیاده‌سازی‌شده

همه‌ی ماژول‌های هسته کسب‌وکار PRD §4 پیاده‌سازی شده‌اند:

- **CORE** — ورود OTP + رمز، احراز دو مرحله‌ای (CORE-01)، کسب‌وکار و شعبه
  (CORE-02)، نقش/دسترسی، اعضا و نقش سفارشی (CORE-03)، تنظیمات (CORE-04)،
  لاگ و ممیزی (CORE-05)، پشتیبان‌گیری ۳۰ روزه (CORE-06)، RTL و تقویم شمسی
  (CORE-07)، تنظیمات اعلان چندکاناله (CORE-08).
- **CRM** — پرونده مشتری، برچسب، قیف فروش، یادآور مراجعه مجدد (CRM-04)،
  تکراری‌یاب (CRM-05)، ورود گروهی و CSV (CRM-06)، فرم/صفحه آنلاین (CRM-07)،
  تاریخچه کامل خط زمانی (CRM-02).
- **SCH** — خدمات، نوبت‌دهی با تشخیص تداخل، لیست انتظار (SCH-07)،
  جلسات تکرارشونده (SCH-08)، قوانین زمانی و زمان‌های آزاد (SCH-03)،
  سیاست لغو/جریمه و مشتری پرریسک (SCH-04)، یادآور خودکار (SCH-05)،
  رزرو گروهی (SCH-06)، همگام‌سازی تقویم — اسکلت (SCH-09).
- **FIN** — فاکتور با مالیات، پرداخت دستی/آنلاین، پیش‌فاکتور و تبدیل (FIN-02)،
  کیف پول و اعتبار (FIN-06)، استرداد با تأیید مدیر (FIN-07)، کد تخفیف (FIN-08)،
  گزارش مالیاتی (FIN-09)، اقساط (FIN-04)، هزینه‌ها (FIN-10)، سود و زیان (FIN-11)،
  صندوق (FIN-12)، لینک پرداخت + QR و SMS (FIN-13)، گزارش بدهکاران (FIN-05).
- **ATT** — حضور و غیاب مشتری/کارمند + خلاصه، جبران جلسه (ATT-04)،
  هشدار افت حضور (ATT-05)، حضور مکانی/ژئوفنس (ATT-07).
- **MSG** — قالب پیام، ارسال تکی و گروهی، رضایت/لغو اشتراک، آمار ارسال،
  گفتگوی فردی + اشتراک فایل (MSG-05)، بسته پیامکی و گزارش مصرف (MSG-07).
- **SUB** — طرح عضویت، اشتراک، بسته جلسه، تمدید خودکار، انجماد، ارتقا،
  تخفیف خانوادگی (SUB-06).
- **CAMP** — کمپین جمع‌آوری وجه، سهم‌بندی (CAMP-03)، پرداخت آنلاین کمک (CAMP-04)،
  شفافیت هزینه (CAMP-07)، بستن خودکار (CAMP-08)، تشکر و گزارش نهایی (CAMP-09)، رسید (CAMP-10).
- **INV** — کالا، سند ورود/خروج، حداقل موجودی، انقضا/Lot، بارکد، تولید QR (INV-07)،
  انتقال شعبه، انبارگردانی.
- **HR** — پروفایل کارمند، مرخصی، کارنامه، فیش حقوقی و پورسانت،
  نگاشت کارمند↔خدمت و تخصیص منصفانه (HR-05).
- **MKT** — باشگاه مشتری، معرفی دوست، کارت هدیه، نظرسنجی، نظرات، صفحه عمومی (MKT-07)،
  کمپین پیامکی هدفمند با بخش‌بندی (MKT-04)، کارت اشتراک شبکه‌های اجتماعی (MKT-08).
- **SHOP** — کاتالوگ، سبد و پرداخت (SHOP-02)، سفارش، جریان وضعیت، ارسال/رهگیری،
  برگه سفارش، و **بازارگاه عمومی** (`/marketplace`) برای گردآوری محصولات و خدمات
  همهٔ اصناف با خرید مهمان — جزئیات در `docs/MARKETPLACE.md`.
- **DOC** — قالب قرارداد، قرارداد با متغیر، امضای الکترونیکی، بایگانی،
  یادآور انقضا (DOC-04)، رضایت‌نامه (DOC-05).
- **RPT** — داشبورد، درآمد، عملکرد، مشتریان، خروجی CSV/چاپ (RPT-05)، پیش‌بینی (RPT-06).
- **APP** — پورتال کاربر نهایی: ورود OTP (APP-01)، رزرو/لغو (APP-02)،
  فاکتور و پرداخت (APP-03)، تاریخچه شخصی (APP-04)، پیام و اعلان (APP-05)،
  باشگاه و کیف پول (APP-06)، نظردهی (APP-07).

### زیرساخت پس‌زمینه

- صف BullMQ (`messages`, `notifications`, `automation`, `reports`) با Redis.
- زمان‌بندهای تکرارشونده: یادآور نوبت، تمدید اشتراک، اقساط معوق، کسر مصرف خدمت.
- سرویس ایمیل چندکاناله + اعلان‌رسانی (CORE-08) و ذخیره‌سازی فایل (DOC-03).

> صفحه‌ی کاربری هر ماژول در `apps/web/src/app/(app)/` قرار دارد: `subscriptions`,
> `inventory`, `staff`, `marketing`, `shop`, `documents`, `campaigns`, `finance`, `team`.

### بنل ادمین پلتفرم (`/admin`)

پنل مدیران کل پلتفرم با هویت و توکن مستقل از کسب‌وکارها:

- ورود با رمز عبور یا OTP (`/admin/login`) — حساب توسعه: `09120000001 / Admin@12345`
- **ورود دو مرحله‌ای (۲FA) اجباری** با TOTP؛ صفحه‌ی `/admin/account` برای ثبت‌نام/غیرفعال‌سازی
- داشبورد آمار، فهرست و جستجوی کسب‌وکارها، جزئیات ۳۶۰ درجه
- **فعال/غیرفعال/افزودن/حذف دستی ماژول‌ها** با حل وابستگی و آبشار معکوس
- ویرایش دستی کسب‌وکار، تغییر وضعیت (فعال/غیرفعال/آرشیو)، حذف نرم و بازیابی
- مدیریت کاربران پنل کسب‌وکار: ویرایش، فعال/غیرفعال کردن، بازنشانی رمز، بستن نشست
- CRUD پلن‌ها و تخصیص پلن به اشتراک، مدیریت مدیران پلتفرم، ممیزی کامل

نقش‌ها: `SUPER_ADMIN` > `ADMIN` > `SUPPORT`. در `apps/api/src/modules/admin/` و
`apps/web/src/app/admin/` پیاده‌سازی شده است.

> ۲FA با `PLATFORM_2FA_REQUIRED` کنترل می‌شود (پیش‌فرض: در production روشن،
> در توسعه خاموش). ماژول‌های هر کسب‌وکار در زمان درخواست با گارد
> `ModuleAccessGuard` و دکوراتور `@RequireModule(...)` اعمال می‌شوند.


## پرداخت و OTP

هر دو به‌صورت provider-based طراحی شده‌اند:

- **درگاه پرداخت:** `mock` (حالت دولوپر/شبیه‌ساز) + `zarinpal` (اسکلت درگاه
  اصلی). افزودن «بنل» یا هر درگاه دیگر = افزودن یک provider جدید، بدون تغییر
  در سرویس‌ها و فرانت.
- **پیامک/OTP:** `console` (توسعه) + آمادگی برای `kavenegar` / `mellipayamak`.

تنظیم با `PAYMENT_PROVIDER` و `SMS_PROVIDER` در فایل `.env`.
